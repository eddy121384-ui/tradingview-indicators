# AGENTS.md — TradingView Indicators

Build reliable TradingView indicators and quantitative research. GitHub is the source of truth.

## Principles

- Work autonomously. Read only what's relevant and use your judgment.
- Prefer simple, focused solutions. Avoid overengineering, speculative abstractions, and unnecessary documentation.
- Preserve existing behavior unless changes are requested.
- Verify proportionally to risk. Never fabricate tests, market data, or research results.
- For trading logic, guard against lookahead bias, repainting, and misleading signals.
- For preregistered research, preserve frozen protocols and separate exploration from validation.
- Respect existing branches and others' work. Never merge, force-push, or overwrite unrelated changes without authorization.
- Keep changes and final reports concise. Explain meaningful limitations.

**Deliver trustworthy results, not elaborate processes.**
