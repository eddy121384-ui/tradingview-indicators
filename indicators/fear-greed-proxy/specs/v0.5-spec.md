# Shiori Fear & Greed Proxy v0.5 規格書

## 1. 文件定位

本文件記錄 `Shiori Fear & Greed Proxy v0.5` 的實際功能與發布候選狀態。

v0.1 規格書保留為原始設計藍圖；本 v0.5 規格書則同步目前 Pine Script 實作、UI 功能、資料代理方式與發布前注意事項。

對應程式碼：

```text
indicators/fear-greed-proxy/src/shiori_fear_greed_proxy_v0_5.pine
```

對應發布文案：

```text
indicators/fear-greed-proxy/docs/tradingview-publish-description-v0.5.md
```

## 2. 指標定位

Shiori Fear & Greed Proxy 是一個 TradingView / Pine Script v6 指標，用於建立 CNN-like 的市場恐懼與貪婪代理分數。

本指標不是 CNN 官方 Fear & Greed Index，也不宣稱能完全複製 CNN 的資料源、公式、權重或歷史校準方式。

本指標定位為：

```text
透明、可調參、可視覺化、可多語顯示的市場情緒溫度計。
```

用途是觀察市場目前偏向恐懼、中性、貪婪，或是否進入情緒極端。本指標不提供買賣訊號，也不應單獨作為進出場依據。

## 3. 版本摘要

v0.5 是目前的發布候選 UI 版本，建立在 v0.4 的計算邏輯上。

v0.5 主要新增：

1. Pine Script v6。
2. 四語 Dashboard 顯示：English、繁體中文、日本語、한국어。
3. 預設語言為 English。
4. TradingView 設定頁 tooltip 以中英日韓四語說明。
5. Dashboard 顏色可自訂。
6. Regime / 情緒區間顏色可自訂。
7. 保留 Put/Call slot，但預設關閉。
8. 保留 v0.4 的計算修正：Strength 百分位化、Breadth 報酬差、Put/Call guard、cold-start mask。

## 5. 七大因子與目前 proxy

### 5.1 Market Momentum

衡量股票價格相對長期均線的強弱。

預設資料：

```text
symbolEquity = SPY
maLen = 125
```

計算方式：

```text
(close / SMA(close, maLen) - 1) * 100
```

之後使用 rolling percentile rank 轉為 0–100 分。

### 5.2 Stock Price Strength

原始 CNN 概念為市場內 52 週新高與新低家數對比。

v0.5 使用安全 proxy：

```text
SPY 位於自身 52 週高低區間的位置
```

再使用 rolling percentile rank 標準化，避免直接把 52 週 range position 與其他 percentile 因子混用。

### 5.3 Stock Price Breadth

原始目標是衡量市場參與廣度。

v0.5 使用：

```text
ROC(RSP, relativeReturnLen) - ROC(SPY, relativeReturnLen)
```

其中：

```text
RSP = 等權重股票 proxy
SPY = 市值加權股票 proxy
relativeReturnLen = 20（預設）
```

正值代表等權重表現優於市值加權，市場參與較廣。負值代表市場由大型權值股主導，參與度較窄。

### 5.4 Put/Call Options

Put/Call 因子保留為可選 slot，但預設關閉。

預設設定：

```text
symbolPutCall = CBOE:VIX
wPutCall = 0.0
```

防呆邏輯：

```text
putCallActive = wPutCall > 0 and symbolPutCall != symbolVix
```

若使用者未將 `symbolPutCall` 改成真正的 Put/Call 商品代碼，即使將權重打開，也不會啟用此因子，避免 VIX 被重複計算。

可用候選需由使用者在 TradingView 帳號內自行確認，例如 PCSP、PCSX、PCQQ 等。

### 5.5 Market Volatility

使用 VIX 相對自身均線的偏離，並反向處理。

預設資料：

```text
symbolVix = CBOE:VIX
vixMaLen = 50
```

計算方式：

```text
(VIX / SMA(VIX, vixMaLen) - 1) * 100
```

VIX 相對壓力越高，代表恐懼越高，因此 score 需反向：

```text
score = 100 - percentile_rank(vixMetric)
```

### 5.6 Safe Haven Demand

衡量股票相對債券的近期表現。

預設資料：

```text
symbolEquity = SPY
symbolBond = IEF
relativeReturnLen = 20
```

計算方式：

```text
ROC(SPY, relativeReturnLen) - ROC(IEF, relativeReturnLen)
```

正值代表風險偏好較強；負值代表避險需求較強。

### 5.7 Junk Bond Demand

衡量高收益債相對債券 proxy 的近期表現。

預設資料：

```text
symbolJunk = HYG
symbolBond = IEF
relativeReturnLen = 20
```

計算方式：

```text
ROC(HYG, relativeReturnLen) - ROC(IEF, relativeReturnLen)
```

正值代表信用風險偏好較強；負值代表信用市場偏防守。

## 6. 標準化與加權

大多數因子使用 rolling percentile rank 轉換為 0–100 分。

預設 lookback：

```text
lookback = 252
```

加權方式：

```text
weightedSum = sum(score_i * weight_i)
weightSum = sum(valid_weight_i)
finalScore = weightedSum / weightSum
```

每個因子都有獨立權重，權重設為 0 即關閉該因子。

預設啟用因子：

```text
Momentum = 1.0
Strength = 1.0
Breadth = 1.0
Put/Call = 0.0
VIX = 1.0
Safe Haven = 1.0
Junk Bond = 1.0
```

## 7. 缺值處理模式

支援三種模式：

```text
Strict
Auto Reweight
Proxy Lite
```

### Strict

要求所有已啟用因子都有有效資料，否則不顯示總分。

### Auto Reweight

使用可用因子重新配權。這是預設模式。

### Proxy Lite

保留作較寬鬆代理模式，適合資料源不完整時使用。

最低有效因子數：

```text
minValidFactors = 4
```

## 8. Cold-start / 暖機邏輯

由於 percentile rank 需要足夠歷史資料，v0.5 在歷史資料不足時不顯示最終分數。

邏輯：

```text
finalScore = bar_index < lookback ? na : rawScore
```

Dashboard 會顯示 warmup 狀態。

四語顯示：

```text
Warming up / 暖機中 / ウォームアップ中 / 워밍업 중
```

## 11. 四語 UI 與 tooltip

v0.5 的語言切換由 input 控制：

```text
language = English / 繁體中文 / 日本語 / 한국어
```

預設值：

```text

```

TradingView 的 input title 無法動態切換語言，因此保持英文。說明文字透過 tooltip 提供中英日韓四語版本。

