# Wyckoff Regime Radar

Wyckoff Regime Radar 是用來協助判讀威科夫結構、吸籌／派發與市場 regime 的 TradingView 指標專案。

## 資料夾結構

```text
specs/      # 規格書、版本設計、功能需求
docs/       # 使用說明、發布文案、教學文件
prompts/    # 給 ChatGPT / Codex / 繪圖模型的提示詞
src/        # Pine Script 原始碼
assets/     # 圖片、截圖、視覺素材
archive/    # 舊版與棄用文件
```

## 指標定位

本指標用來輔助辨識市場是否可能處於吸籌、派發、趨勢延伸或結構轉換階段。它不是單一進場訊號，而是結構判讀與風險控管工具。

## 初始狀態

此資料夾目前為初始化骨架，後續請將 Wyckoff Regime Radar 的規格書、Pine Script、使用說明與發布文案逐步放入對應資料夾。
