## What has already been established

### B3.5 — Core memory is not the long reversal-lag source

- Opposite Formal family -> Core flip lag = 0 bars.
- STRONG -> Formal lag max 2 bars.
- Therefore the months/year-scale stale-bias seen on rates charts is not caused by B3.3 Core memory or Formal persistence.

### B3.6 — Strong-gate blockage is not the primary long-lag source

Frozen FX attribution found local Strong blockage mostly from Gap/Conflict, but FR10Y/JGB10Y human review showed that the long reversal lag usually begins before Strong formation. The problem was localized further upstream.

### B3.7 — TOP ranking is usually decided at RAW layer

On frozen FX, when a target trend family failed to become TOP:

- ~93.7% were already losing at Raw-score layer.
- ~6.3% were Raw winners later flipped by gates.

Thus downstream gate tuning is not the main repair path.

## Current phase — B3.14 Break Evidence Memory

Question:

When Break is the final negative component before an S5->S2 or reciprocal S2->S5 raw handoff, is the old side being supported by stale prior event memory, or is the new side simply missing comparable breakout evidence?

### Current Break mechanism under audit

Break evidence combines the strongest available source from:

- range-break evidence / recent range-break memory
- MA-cross evidence / recent MA-cross memory
- breakout/breakdown mode

The audit does not change any Break formula.

### Frozen-FX mechanical result — PASS

B3.14 mechanically reproduced all **106** Break-final-blocker events from B3.10.

Engineering invariants:

- reproduction delta: 0
- reciprocal boolean attribution: 100%
- reciprocal source-family attribution: 100% (106/106)
- no performance metrics used

At t-1 before those handoffs:

- old-side recent-event memory active: **105 / 106 (99.1%)**
- old-side range-break memory active: **101 / 106 (95.3%)**
- old-side MA-cross memory active: **76 / 106 (71.7%)**
- old-side mode active: **1 / 106 (0.9%)**
- target-side range evidence present: **5 / 106 (4.7%)**
- target-side MA evidence present: **50 / 106 (47.2%)**
- current price already on target side of MA50: **20 / 106 (18.9%)**

Most common source pairings:

- target MA -> old range memory: 48
- target none -> old range memory: 45
- target none -> old MA memory: 10
- target range -> old range: 2
- target none -> old mode: 1

Mechanical interpretation:

- Old range-break memory is genuinely a major Break blocker source.
- However only 18.9% of these events occur after price is already on the target side of MA50.
- Therefore `breakoutBars=20 is too stale` is **not established** yet.
- The evidence currently supports a narrower hypothesis: during regime handoff, the old side often retains recent range-break evidence while the new side has only MA evidence or no comparable range-break evidence yet.

## Exact next step

Continue with a focused **B3.15 Event-Window / Stale-Memory Audit**, unless an even simpler direct inspection of the B3.14 Pine around yellow events is sufficient.

The next diagnostic should answer:

1. Around each Break-final-blocker event, when does current MA side first move to the new direction?
2. How many bars does old range-break memory remain active after that point?
3. When does target-side new range evidence first appear?
4. During the interval `MA side already new` + `old range memory still active`, does Break remain old-side, and for how many bars?
5. Is that interval materially longer in FR10Y/JGB10Y adverse regimes than in ordinary FX/control regimes?

Preferred design:

- No new thresholds.
- No tuning of `breakoutBars` yet.
- Use exact existing event timestamps and exact existing Break-source booleans.
- Measure event-window delays directly in bars.
- Preserve reciprocal symmetry contracts.
- No PnL / Strategy Tester.

If B3.15 shows a substantial, systematic post-MA-side stale-memory interval in adverse rates cases, then a memory-decay / handoff-rule shadow can be preregistered.

If B3.15 shows old range memory mostly expires before or near target-side market confirmation, then do **not** shorten the memory window; instead investigate why new target-side range-break evidence forms so late.
