# Shiori Map

Shiori Map 是用來協助判讀市場狀態、趨勢方向與風險語氣的 TradingView 指標專案。

## 資料夾結構

```text
specs/      # 規格書、版本設計、功能需求
docs/       # 使用說明、發布文案、教學文件
prompts/    # 給 ChatGPT / Codex / 繪圖模型的提示詞
src/        # Pine Script 原始碼
assets/     # 圖片、截圖、視覺素材
archive/    # 舊版與棄用文件
```

## 指標定位

本指標的核心不是提供單一買賣訊號，而是協助使用者理解市場目前所處的狀態，避免站錯邊與過度交易。

## 初始狀態

此資料夾目前為初始化骨架，後續請將 Shiori Map 的規格書、Pine Script、使用說明與發布文案逐步放入對應資料夾。
