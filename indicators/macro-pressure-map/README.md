# Macro Pressure Map

Macro Pressure Map 是用來整理成長、通膨、政策與市場壓力的 TradingView 指標專案。

## 資料夾結構

```text
specs/      # 規格書、版本設計、功能需求
docs/       # 使用說明、發布文案、教學文件
prompts/    # 給 ChatGPT / Codex / 繪圖模型的提示詞
src/        # Pine Script 原始碼
assets/     # 圖片、截圖、視覺素材
archive/    # 舊版與棄用文件
```

## 指標定位

本指標用來協助觀察總經壓力軸，包含成長、通膨與政策敘事的狀態變化。它不是單一進場訊號，而是市場環境判讀工具。

## 初始狀態

此資料夾目前為初始化骨架，後續請將 Macro Pressure Map 的規格書、Pine Script、使用說明與發布文案逐步放入對應資料夾。
