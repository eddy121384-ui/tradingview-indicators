# Macro Pressure Map — 研究目的與執行順序

> **北極星：用成長、通膨、金融條件的「水準 × 方向」辨識資產的相對機會、重大風險及可能轉折，歸納能跨經濟週期檢驗的配置原則。**
>
> 這不是要為每個象限強行指定投資權重，也不是預測短線漲跌或不斷增加 TradingView 提示文字。

**現有研究成果**：[宏觀資產配置證據地圖](docs/allocation-evidence-map.md)（已證實／證據不足／下一個待研究缺口）。

## 我們究竟要回答什麼？

1. **股票 vs 長債**：何時較值得承擔股票風險？何時應降低股票、增加 Duration？
2. **長債 vs 現金**：什麼成長／通膨條件下，長債可能不再是好的避險資產，甚至應大幅減碼？
3. **轉折**：成長與通膨仍處於低檔、但停止惡化或開始回升時，是否提前反映在股票／債券相對報酬？
4. **金融條件**：壓力水準與收緊／放鬆速度，是否改變前述偏好、下檔風險或轉折可靠度？
5. **避險資產**：黃金、原物料等是否在特定環境有增量價值？沒有證據就不給建議。

**必須分開研究**：(a) GPI／IPI／FCPI 或歷史結構分數的**相對水準與變化**；(b) 真實經濟量的**絕對背景**（如 CPI 年增率、失業率、利率）。標準化壓力分數「+10」不等於通膨率「10%」。同一分數在不同絕對通膨年代，可能有不同債券意義。

## 新的研究起點：Literature-first, Replication-first

**先查學界與業界已有哪些成熟方法，再決定 GPI／IPI／FCPI 要解決什麼尚未解決的問題。** 不要從零發明一套配置系統，或只跟自己設計的靜態組合比較。

1. **先盤點、再挑基準**：優先檢視長歷史股市減碼／熊市防護（10 個月均線、12 個月動能、Time-Series Momentum）、經濟週期與金融條件配置、波動度目標、股債輪動等**現成學術／實務方法**。記錄原始研究出處、明確規則、歷史期間、失效環境、交易限制和是否可獨立重現；不預設任何方法已經普遍有效。
2. **先重現 3–5 種有代表性的成熟基準**：在可能的最長可靠歷史上，以原生指數／含息資產報酬而非 ETF 上市期間決定主樣本；同時嚴守無未來資訊、樣本外、資料修訂與執行成本界線。重現不了就註明原因，不自創替代結果。
3. **最後驗證宏觀指標的增量價值**：分別比較純宏觀、純價格趨勢、宏觀＋價格等設計，衡量減碼時機、熊市下檔、牛市錯過的漲幅、換手與**相同平均風險曝險**下的績效。若宏觀資訊無法穩定改善成熟基準，接受 **No Edge／No View**，不為發表新指標而硬造訊號。

這是後續新研究的**方法與優先順序**；不改寫既有凍結 prereg 或歷史 findings，也不授權立即回測或產品化。

## 研究順序（不要顛倒）

1. **盤點現有證據與缺口**：先讀 #91、#160、#174、#188、#189 及相關 findings。保留負面／不足證據，不重做已完成研究。寫清楚每項結論適用的模型、樣本與限制。
2. **建立可信的長歷史基礎**：以原始經濟統計、長歷史金融條件代理，以及股票指數／國債／國庫券等**含股息與票息的歷史報酬**為主；ETF 只作現代可交易性或資料交叉檢查，不用其上市日期限制主要樣本。先聚焦股、長債、現金；黃金／原物料視資料品質擴張。#174 已指出部分指數為 price-only、油為 spot，不能把它們當作完整投資總報酬。
3. **先研究環境，再研究轉折**：在預先固定的長歷史模型下，分別衡量水準、方向、兩者交互作用與金融條件的**增量資訊**。比較股票−長債、長債−現金的後續相對報酬、下檔、極端事件與轉折領先／落後；不預設某象限必然偏多某資產，也不直接擴張成 27 象限。
4. **才提出少量、可反駁的配置原則**：每條規則都要說明觸發背景、經濟機制、對照的固定配置、歷史反例、跨時代穩定性，以及「何時 No View」。先測相對偏好與風險調整，最後才談具體權重。
5. **驗證可交易性後才考慮產品化**：考慮公布時間、修訂、執行落後、成本與真正的新資料。#189 顯示完整原始 Deep History PIT 無法確認，**修訂後歷史的關聯不是已證明可即時交易的優勢**。若 PIT 無法取得，誠實保留描述性結論，並用前瞻記錄累積新證據。

## 必守邊界

- **現代 exact V6.6 ≠ 1928／1960 年代的結構歷史模型**；GPI／IPI／FCPI 的現代市場成分不能假裝存在於古早年代。歷史 FCPI 若無可靠代理，明示缺口，不用事後填值，也不阻礙先研究 Growth × Inflation。
- 凍結定義後再看資產結果。不得因績效而挑來源、調門檻、改權重、改回測期間或偷用未來資訊；先區分探索、重複使用的樣本、真正新證據。
- 與**簡單固定配置、相同曝險／風險對照**比較；優先檢驗經濟意義、符號穩定性、危機保護與錯判代價，而非追求漂亮 CAGR。
- **功能不是研究成果**：#129／#190 的 Shadow／資訊展示只是產品實驗。不能用「畫面顯示成功」替代「資產配置資訊真的有增量價值」。
- 沒有可靠資料、跨年代不穩定或不足以改變決策時，結論可以是 **No View／證據不足**；不要為填滿九象限而繼續挖參數。

## 工作習慣

新研究開始前，先用幾句話寫清楚：**它回答上述哪個問題？現有證據缺什麼？最小可行驗證是什麼？什麼結果會讓我們停止？** 若答不出來，先不要開新 Issue 或寫新程式。

本 README 是**方向與優先順序**，不是修改已凍結研究規格的授權。具體數值、方法和已知限制以各 Issue 的 prereg／finding 為準。Production／merge 須另行明確授權。
